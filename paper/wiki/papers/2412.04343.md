## 一句话总结

RMD 提出一种**无需额外训练**的检索增强动作生成 baseline：用 LLM 把文本 prompt 按身体层级（全身 → 半身 → 六部位）分解，对每个部位检索最匹配的动作片段并进行四元数插值组合，最后将组合结果注入预训练 diffusion 模型（SDEdit 方式）进行去噪精炼，在 OOD 场景下显著优于纯生成方法。

## 解决什么问题

1. **数据集多样性瓶颈**：HumanML3D 等数据集规模有限，纯生成模型面对分布外（OOD）描述时质量大幅下降。
2. **现有检索方法依赖额外训练**：ReMoDiffuse、DLP 等 RAG-T2M 方法需要在训练阶段引入检索模块，无法灵活更换外部运动数据库。
3. **全身级检索的局限**：当数据库中没有完全匹配的全身运动时，全身级检索必然失败；需要一种部位级组合机制来合成 OOD 运动。

## 核心方法

### 1. LLM 动作分解 Agent (Section 3.1)

给定文本描述，用 GPT-4o 生成两个粒度的身体部位描述：

- **半身级**：上身 / 下身
- **细粒度级**：头部、躯干、左臂、右臂、下半身、全局轨迹

对多 prompt 描述，将它们拼接后统一告知 LLM"这些描述同一个动作"。每条 query 做 $k = 5$ 次分解，检索候选后再由 LLM 根据整体语义一致性选出最佳组合。

### 2. 层级式动作检索 (Section 3.2)

检索打分公式结合 CLIP 语义相似度与长度惩罚：

$$s_i = \langle f_i^t, f_p^t \rangle \cdot e^{-\lambda \cdot \gamma}, \quad \gamma = \frac{|l_i - l_p|}{\max\{l_i, l_p\}}$$

其中 $\lambda = 0.05$ 控制长度惩罚权重。

层级策略按阈值级联：
1. 全身检索得分 $\geq \tau_{\text{full}}$ → 直接采用全身结果
2. 半身检索得分 $\geq \tau_{\text{half}}$ → 上下身独立检索并组合
3. 否则 → 六部位细粒度检索与组合

$\tau_{\text{half}} = \tau_{\text{fine}} = 0.96$。

**动作组合**：对各部位检索到的四元数表示做 SLERP 插值、平移做线性插值，将不同长度的片段统一 rescale 到目标长度后拼合为完整姿态。

### 3. 检索增强动作扩散 (Section 3.3)

采用 SDEdit 机制：将组合后的动作 $x^{(g)}$ 加噪到中间时间步 $t_0$：

$$x = x^{(g)} + \sigma(t_0) z, \quad z \sim \mathcal{N}(0, I)$$

然后用 DDIM 从 $t_0$ 去噪到 $t = 0$。去噪步 $n$ 的更新：

$$\varepsilon = \sqrt{\sigma^2(t) - \sigma^2(t - \Delta t)}, \quad x = x + \varepsilon^2 s_\theta(x, t) + \varepsilon z$$

其中 $t = t_0 (n/N)$，$\Delta t = t_0 / N$，$s_\theta$ 为预训练 score 模型。

**关键超参 $t_0$**：$t_0$ 小 → 保留更多检索 guide 信息；$t_0$ 大 → diffusion prior 主导（$t_0 = 1$ 等价于标准扩散采样，完全丢弃 guide）。最优值为 $t_0 = 0.96$。

33 条 OOD prompt、16 位用户评测，文本对齐度和自然度均显著优于 MDM、MotionDiffuse、MoMask、ReMoDiffuse。

## 局限与 Gap

1. **$t_0$ 需手动调节**：作者承认 $t_0$ 的最优值因 retrieval-training 分布匹配程度不同而变化（Table 7 示：检索库与训练集不匹配时最优 $t_0 = 0.8$），自动化选择尚未解决。
2. **检索空间局限于 CLIP 文本级**：语义匹配完全依赖 CLIP 文本 embedding + 长度惩罚，无 motion-level 或 latent-level 的相似度度量，无法捕捉动作空间的结构信息。
3. **无学习式检索器**：检索完全基于冻结 CLIP，没有 fine-tune 适配 motion 领域的对比学习（对比 TMR / BMM 等学习式检索器）。
4. **组合质量受限于 SLERP 插值**：身体部位间的过渡仅靠四元数 SLERP + 线性插值，物理合理性和平滑性依赖后续 diffusion 精炼来兜底。
5. **LLM 推理开销**：每条 query 需 $k = 5$ 次 GPT-4o 调用做分解 + 1 次 LLM 选择，推理成本和延迟不可忽视。
6. **评价指标局限**：FID 等指标在 OOD 场景缺乏参考分布，用户研究规模较小（16 人、33 条 prompt）。

## 与 ReMoMask V2 的关联

### Plan A（latent 对齐检索）

- **直接对比点**：RMD 在 **CLIP 文本空间** 做检索，ReMoMask V2 Plan A 要把检索空间迁移到 **VQ-VAE latent space**。RMD 的 Table 7 实验表明检索库和训练集分布不匹配时性能显著下降（$t_0$ 最优从 0.96 降到 0.8，R-Precision Top-1 从 52.4% 降到 46.5%），恰好佐证了"对齐检索空间与生成空间"的必要性——这正是 Plan A 要解决的核心问题。
- **部位级分解可借鉴**：RMD 的层级分解思路（全身 → 半身 → 六部位）在 latent space 下可类比为"对 latent token map 的空间区域做分区检索"，与 ReMoMask V1 的 Part_TMR 分区逻辑相呼应，但粒度更灵活。
- **SDEdit 精炼机制**：RMD 用 diffusion 模型从中间 $t_0$ 去噪来"兜底"检索组合的不完美，Plan A 可借鉴类似策略——latent 级检索结果注入 masked transformer 后，用 iterative refinement 代替 SDEdit 做类似的修正。

### Plan B（迭代动态检索）

- **LLM Agent 多轮分解**：RMD 的 $k = 5$ 次分解 + LLM 选择本质上是一种 query 增强策略，Plan B 的迭代检索可以在每轮用类似方式动态调整 query（不依赖 LLM，而是用生成中间结果的 embedding 做 re-query）。
- **层级级联阈值**：阈值 $\tau$ 控制何时从全身退化到细粒度，这种"检索信心 → 决定策略"的思路可直接复用于 Plan B 的迭代终止条件（检索信心够高则停止迭代）。

### 实验设计参考

- RMD 的跨数据集（Mixamo）评测和 OOD 用户研究设计值得 V2 论文复用，特别是"分解策略分布随 OOD 程度变化"的分析维度。
- Table 7 的 retrieval-training mismatch 实验可作为 Plan A "latent 对齐"必要性的佐证文献。
