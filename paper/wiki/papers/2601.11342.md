## 一句话总结

SPREAD 针对 Diffusion Language Model (DLM) + RAG 场景，发现 confidence-based denoising 策略导致生成内容逐句偏离 query 语义（Response Semantic Drift, RSD），提出以 query-token 语义相关度取代 confidence 来选择每步解码的 token，在 6 个 QA benchmark 上大幅提升 precision（LLaDA +15.34%、Dream +30.90%）。

## 解决什么问题

1. **DLM + RAG 尚无系统研究**：DLM（LLaDA、Dream 等离散扩散语言模型）具有并行解码与迭代 refinement 优势，但 RAG 整合仍为空白——直接套用 LLM 的 RAG pipeline 效果受限。
2. **Recall 高但 Precision 低**：初步实验（Table 1）显示 DLM 在 RAG 下 copy rate 高（如 Dream NQ 84.81%）且 F1 可与 LLM 持平甚至更高，但 precision 显著偏低（Figure 1），生成内容含大量与 query 无关的冗余上下文。
3. **Response Semantic Drift (RSD)**：作者形式化了一种新现象——生成答案中相邻句子间的语义距离渐进增大，导致输出在局部连贯但整体偏离 query。RSD 定义为：

$$\text{RSD}(a) = \frac{1}{|S|-1}\sum_{i=1}^{|S|-1}\text{Dist}(s_i, s_{i+1})$$

其中 $\text{Dist}(s_i, s_{i+1}) = 1 - \text{cosine}(\text{Enc}(s_i), \text{Enc}(s_{i+1}))$。

4. **根因在 denoising 策略**：confidence-based / entropy-based 策略仅依据模型对 token 的全局置信度排序 unmask 优先级，缺乏与 query 语义的全局对齐，导致每步微小偏差在迭代中累积放大。

## 核心方法

### SPREAD 框架（Algorithm 1）

在标准 DLM 去噪循环的每一步 $t$ 中插入两个模块：

**1. Query-Token Semantic Relevance Assessment**

利用模型前向传播已有的 hidden states（最后一层 $h_i \in \mathbb{R}^d$），无需额外编码，计算每个 masked 位置 $i$ 与 query $q$ 的语义相关度：

$$\text{Sim}(i, q) = \frac{h_i \cdot h_q}{\|h_i\|\|h_q\|}$$

$$\text{Rel}(i, q) = \sigma(\text{Sim}(i, q))$$

其中 $\sigma$ 为 Sigmoid 函数，将相似度映射到 $(0,1)$。

**2. Relevance-Guided Token Selection**

用 $\text{Rel}(i, q)$ 排序所有 masked 位置，取 top-$k$ 最相关的位置解码（unmask），其余保持 mask 等待后续步骤 refinement。

**核心洞察**：用 query 语义相关度取代模型 confidence 作为 unmask 优先级标准，从而将去噪轨迹锚定在 query 语义上，抑制漂移。

### 实现细节
- Retriever: NV-Embed-v2 dense encoder, chunk 2000 chars, top-5 passages
- Diffusion steps: 128, max new tokens: 512, temperature: 0.1
- 额外计算开销极小：复用前向 hidden states，Dream 上仅增 0.68s，LLaDA 仅增 0.23s

## 关键实验结果

**Table 2 — 主实验（6 个 QA 数据集，Precision / RSD）**

| 模型 | 策略 | NQ P | NQ RSD | Trivia P | HotpotQA P | MuSiQue P | Multihop P | UltraDomain P |
|---|---|---|---|---|---|---|---|---|
| LLaDA | random | 20.63 | 29.35 | 30.38 | 35.60 | 19.28 | 28.07 | 21.58 |
| LLaDA | low-conf | 26.05 | 23.01 | 36.04 | 41.38 | 23.91 | 44.91 | 23.89 |
| LLaDA | **SPREAD** | **30.37** | **21.79** | **42.46** | **48.71** | **26.67** | **48.73** | **29.33** |
| Dream | maskgit-plus | 37.11 | 12.60 | 47.08 | 52.42 | 31.35 | 37.05 | 36.24 |
| Dream | entropy | 35.25 | 12.61 | 44.30 | 50.16 | 29.33 | 35.85 | 41.69 |
| Dream | **SPREAD** | **52.79** | **4.83** | **55.71** | **59.37** | **37.78** | **59.09** | **58.19** |

- SPREAD 在 LLaDA 上 Precision 平均绝对提升 +15.34%，RSD 相对降低 >10.92%
- SPREAD 在 Dream 上 Precision 平均绝对提升 +30.90%，RSD 相对降低 >61.18%
- Copy Rate 几乎不变，但 Redundancy 显著下降（Figure 4）——说明问题不在"是否复制"而在"复制什么"
- 效率（Table 3）：Dream SPREAD 19.02s vs maskgit-plus 19.64s，吞吐 31.49 vs 30.72 tokens/s，开销可忽略

**Table 4 — RSD 与其他指标的 Pearson 相关**

| 指标对 | LLaDA | Dream |
|---|---|---|
| RSD-Precision | -0.36 | -0.24 |
| RSD-Redundancy | 0.46 | 0.55 |
| RSD-Copy Rate | -0.30 | -0.16 |

RSD 与 Precision 负相关、与 Redundancy 强正相关，验证了语义漂移是 precision 瓶颈的合理解释。

## 局限与 Gap

1. **检索质量未处理**：SPREAD 只改进 generation 端（denoising 策略），不涉及 retriever 优化；作者承认性能依赖检索上下文的相关性，检索-生成联合优化可形成正反馈但未探索。
2. **仅验证 QA 任务**：未测试开放式生成（故事写作等），泛化性存疑。
3. **离散 DLM 限定**：仅在 LLaDA-8B、Dream-7B 两个离散扩散模型上验证，未涉及连续扩散模型或更大参数规模。
4. **query representation 简化**：query 的语义表示 $h_q$ 仅取最后一层 hidden state 的单一向量，对复杂 multi-hop query 的表征能力有限。
5. **top-$k$ 策略固定**：每步 unmask 的 token 数 $k$ 为预设超参，未自适应调整。

## 与 ReMoMask V2 的关联

### Plan B（迭代动态检索）直接相关

ReMoMask 的 10 步迭代去掩码过程与 DLM 的 masked diffusion denoising 高度同构。SPREAD 的核心思路——**在每个 demasking step 用 query 语义相关度而非 confidence 来决定 unmask 优先级**——可直接迁移到 motion generation：

- **Query-token relevance 的 motion 版本**：在 ReMoMask 的每个去掩码步骤中，用 text query 的 embedding（来自 CLIP/TMR encoder）与各 masked motion token 的 hidden state 计算 cosine similarity，优先 unmask 与 text 最相关的 token，抑制生成动作在时序上偏离文本语义。
- **RSD 指标的 motion 适配**：可定义 Motion Semantic Drift，度量生成动作相邻帧段与 text 的语义距离变化，作为 V2 的新评估指标。

### Plan A（latent 对齐检索）间接相关

- SPREAD 复用模型前向传播的 hidden states 计算 query-token 相关度，**无需额外编码**——这验证了"在同一 latent space 内计算检索/对齐信号"的可行性和高效性，与 Plan A 将检索迁移到 VQ-VAE latent space 的动机一致。
- SPREAD 的 Sigmoid 归一化相关度公式（Eq. 4）可作为 Plan A 中 latent space 内 text-motion alignment score 的参考实现。

### 可借鉴的具体技术

1. **Relevance-guided unmask scheduling**：替换 ReMoMask 当前基于 confidence 的 mask scheduling。
2. **零额外开销的 alignment 计算**：复用 transformer 已有 hidden states，不加编码器。
3. **RSD 度量**：作为 motion generation 质量的补充指标（衡量时序连贯性 vs. text 语义锚定）。
