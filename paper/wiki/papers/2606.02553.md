## 一句话总结

把自回归视频 diffusion 的长视频生成问题建模为 latent 空间的检索增强生成（RAG）：将已生成的 latent 存入可搜索的历史库，每个新 block 生成前按余弦相似度检索 top-K 历史 latent 作为非局部注意力上下文，配合 Window Temporal Delta Loss 训练判别性 embedding，在不修改 base generator 的前提下显著缓解滑窗注意力的误差累积和 identity drift。

## 解决什么问题

自回归视频 diffusion 在生成长视频时依赖滑窗注意力，窗口外的早期内容一旦丢弃就无法再利用。当近期窗口内累积了外观漂移、身份变化或背景伪影，后续 block 只能基于这些退化上下文继续生成，误差不可逆地累积。现有方案分三类，各有局限：

1. **Attention sink / 固定锚点**（如 StreamingLLM）：保留最早的 token 或帧作为锚点，但固定锚点不一定匹配当前内容需求。
2. **位置编码外推**（如 $\infty$-RoPE、RIFLEx）：延长模型可用的时序范围，但不能阻止可见上下文本身已漂移后的误差传播。
3. **压缩历史 token**（如 Deep Forcing、VideoSSM、MemRoPE）：将旧状态压缩为替代 token 或循环记忆，但压缩可能丢失关键原始视觉细节。

LongLive-RAG 的出发点：长视频生成需要一种 **按需调用** 历史状态的机制——当历史中某个早期 block 更好地保留了主体外观或场景结构时，应当能把它检索回来供当前 block 使用，而非只依赖近期窗口或固定摘要。

## 核心方法

### 整体框架

LongLive-RAG 冻结 base AR generator（如 Causal-Forcing、Self-Forcing、LongLive），只在推理时增加一个离线训练好的轻量检索模块。注意力上下文从标准滑窗

$$A^{\text{sw}}_t = [C_{\text{sink}} \| C_{\text{loc}}]$$

扩展为

$$A^{\text{rag}}_t = [C_{\text{sink}} \| M_t \| C_{\text{loc}}]$$

其中 $M_t$ 是检索到的非局部历史上下文。不添加新的注意力层，不改变去噪规则。

### 历史索引

- 对每个已完成的 block $i$，一个卷积 encoder $E_\psi$ 将 clean latent $\hat{x}_i \in \mathbb{R}^{C \times H \times W}$ 压缩为 1024 维 embedding $v_i = E_\psi(\hat{x}_i)$。
- 维护两个配对库：embedding 搜索库 $\mathcal{H}_v = \{(i, v_i)\}$ 和上下文库 $\mathcal{H}_{\text{ctx}} = \{(i, C_i)\}$。
- 检索时以最近已完成 block 的 embedding $v_q = v_{t-1}$ 为 query，按余弦相似度排序：$a_i = \cos(v_q, v_i)$，取 top-K 索引 $\mathcal{I}_t$，对应的上下文 $M_t = [C_i]_{i \in \mathcal{I}_t}$。
- 设有 recency guard $R$，跳过最近 $R$ 个 block，避免检索到与局部窗口近乎重复的内容。

### Embedding 空间训练

仅训练轻量卷积 autoencoder（encoder + decoder），base generator 完全冻结。训练目标包含三项：

1. **重建损失**：$\mathcal{L}_{\text{rec}} = \| D_\psi(E_\psi(\hat{x}_t)) - \hat{x}_t \|_2^2$，保证 embedding 保留视觉内容。
2. **Window Temporal Delta Loss**：

$$\mathcal{L}_\Delta(v_t, v_{\text{ref}}) = \lambda_\Delta \max(0, \cos(v_t, v_{\text{ref}}) - m)$$

在局部时间窗口 $w$ 内平均：

$$\mathcal{L}_{\text{SeqDelta}} = \frac{1}{\bar{w}} \sum_{\tau=1}^{\bar{w}} \frac{1}{T - \tau} \sum_{t=\tau+1}^{T} \mathcal{L}_\Delta(v_t, v_{t-\tau})$$

作用：抑制临近 block 之间过高的余弦相似度（margin $m = 0.85$），防止 top-K 全被局部冗余 block 占满。仅惩罚短程对，不干扰长程合理重现。

3. **二阶轨迹平滑**：$\mathcal{L}_{\text{Smooth}} = \lambda_{\text{smooth}} \frac{1}{T-2} \sum_{t=3}^{T} \| v_t - 2v_{t-1} + v_{t-2} \|^2$，防止 embedding 轨迹过度跳变导致 top-K 集合不稳定。

总损失：$\mathcal{L}_{\text{Total}} = \mathcal{L}_{\text{rec}} + \mathcal{L}_{\text{SeqDelta}} + \mathcal{L}_{\text{Smooth}}$。

### 推理流程（Algorithm 1）

每个 block $t$：
1. 若历史库条目数 $> R$，用 $v_{t-1}$ 查询 $\mathcal{H}_v$ 取 top-K。
2. 组装注意力上下文 $A_t = [C_{\text{sink}} \| M_t \| C_{\text{loc}}]$，执行 $N$ 步去噪。
3. 完成后 encode 新 latent 得 $v_t$，追加到本地缓存；本地缓存溢出时，最老条目移入历史库。

### 关键超参数

| 参数 | 值 |
|---|---|
| Embedding 维度 | 1024 |
| Encoder hidden dims | [64, 128, 256] |
| Delta window $w$ | 3 |
| Delta margin $m$ | 0.85 |
| $\lambda_{\text{rec}}, \lambda_\Delta, \lambda_{\text{smooth}}$ | 均为 1.0 |
| Recency guard $R$ | 5 |
| 检索预算 $K$ | 6（总注意力窗口 12 = 1 sink + 6 retrieved + 5 local） |
| 训练：AdamW, lr $3\times10^{-4}$, batch 128, 400 epochs | |

### 检索开销

120s rollout 全程额外开销仅 490 ms（latent encoding 480 ms + top-K search 10 ms），相对于 diffusion 去噪本身可忽略。

## 关键实验结果

### 实验设置

- 三个 AR backbone：Causal-Forcing、Self-Forcing、LongLive。
- 三个生成长度：30s、60s、120s。
- 对比方法：base model、$\infty$-RoPE（位置外推）、Deep Forcing（压缩历史 token）。
- 评估：VBench-Long 6 项指标 + 辅助 VLM（Gemini 3.1-Pro）打分。
- 全部 128 条 MovieGenBench prompt，用 Qwen2.5-7B-Instruct 精化。

### 主要定量结果（Table 2）

LongLive-RAG 在 **所有 9 个 base-model × duration 组合** 中取得最低 Avg. Rank（均 $\leq 1.67$）。代表性数据：

| 设置 | Subject Cons. | Background Cons. | Motion Smooth. | Imaging Quality | Avg. Rank |
|---|---|---|---|---|---|
| Causal-Forcing 30s + LongLive-RAG | **95.43** | **94.79** | **97.16** | **70.07** | **1.33** |
| Self-Forcing 120s + LongLive-RAG | **97.64** | **96.40** | **98.75** | **64.16** | **1.50** |
| LongLive 60s + LongLive-RAG | **97.32** | 96.08 | 98.62 | **67.79** | **1.33** |

增益在 subject consistency、background consistency、motion smoothness、imaging quality 上最显著。

### VLM 辅助评分（Table 3b，30s，满分 5）

| 方法 | Causal-Forcing | Self-Forcing | LongLive |
|---|---|---|---|
| Base | 2.60 | 3.50 | 4.65 |
| + $\infty$-RoPE | 4.10 | 4.15 | 4.35 |
| + Deep Forcing | 3.55 | 4.35 | 4.70 |
| + LongLive-RAG | **4.70** | **4.45** | **4.75** |

### 消融实验（Table 3a，Causal-Forcing 30s）

- Random retrieval → Subject Cons. 94.54；Avg-pool descriptor → 94.77；AE only → 94.82；AE + SeqDelta → 94.76；**完整方法 → 95.43**。
- 检索预算 $K$：$K=6$ 为最优平衡点；$K=8$ 时 background consistency 和 imaging quality 反而下降（93.07 / 60.02），因为过多检索 slot 挤压了局部窗口。

### 通用性

- 同一个 retrieval encoder 在 WAN VAE latent 空间上训练一次，**不针对各 backbone 重训**，直接迁移到三个不同的 AR backbone 均有效。
- 训练数据：从 Self-Forcing prompt pool 中 10% 采样，生成 90-latent LongLive rollout，共 20,000+ 训练 latent。Autoencoder 训练 < 100 A6000 GPU-hours。

## 局限与 Gap

1. **受限于 base generator 能力**：LongLive-RAG 冻结 base checkpoint，不改变 generator 本身，最终视频质量仍受 base AR model 能力上限约束。
2. **检索 embedding 空间仅从单一 backbone（LongLive）rollout 训练**：虽然实验表明跨 backbone 迁移有效，但训练数据的分布偏差是否在更多样的 backbone 上仍成立，尚未充分验证。
3. **固定检索预算 $K$ 与总注意力窗口大小**：$K=6$ 在窗口 12 下最优，但不同内容复杂度是否需要自适应调整 $K$ 未探讨。
4. **仅在 VBench-Long 和辅助 VLM 上评估**：缺乏人类偏好评估（human preference study）以及更细粒度的 identity 保持度量。
5. **未与基于 3D 几何 / 相机位姿的检索记忆方法**（如 WorldMem、RELIC）在可比场景上对比——后者在有显式空间结构的场景中可能更优。
6. **不支持交互式 prompt 切换时的检索策略调整**：当 prompt 在 rollout 中途发生大幅语义变化时，历史库中的旧内容是否应被降权或清空，论文未讨论。
