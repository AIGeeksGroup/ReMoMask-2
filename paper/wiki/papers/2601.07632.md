## 一句话总结

用正交约束统一 motion codebook 和 LLM embedding 的几何结构：decoder-only quantizer（DVQ）+ Gumbel-Softmax 让 codebook 可微、稀疏投影保结构、两阶段正交正则化保对齐，motion captioning 在 HumanML3D 上 Average 提升 22.4%。

## 解决什么问题

现有 LLM-based motion understanding 管线把 motion tokenization 和 LLM embedding 学习拆成两个独立阶段，中间只靠 token ID 连接。VQ-VAE 先训出 codebook，再把离散 ID 映射到可学习 embedding 扩展 LLM 词表——但 codebook 中各 code 之间的几何关系（距离、角度）从未被显式传递到 LLM embedding 空间。结果 LLM 要从零"猜出"motion token 之间的关系，几何失配制约了 motion reasoning 质量。

具体痛点：
1. **几何断裂**：quantizer 和 LLM embedding 只通过 token ID 连接，codebook 内部的关系结构在映射到 LLM 时丢失。
2. **Codebook collapse**：标准 VQ-VAE 的 nearest-neighbor assignment 不可微，无法对 codebook 施加显式正则，大量 code 使用率极低（dead codes），离散表示的有效容量缩水。
3. **投影失真**：学习一个稠密线性映射把低维 codebook 映射到高维 LLM embedding 时，正交结构被扭曲。

## 核心方法

### 几何对齐思路

将对齐建模为**几何统一问题**：在 motion codebook $C = \{c_1, \ldots, c_K\} \subset \mathbb{R}^D$ 上施加正交约束 $\langle c_i, c_j \rangle \approx \delta_{ij}$，并保证该结构在映射到 LLM embedding 空间后不变。

正交 loss 定义在行归一化 codebook $\hat{C}$ 的 Gram 矩阵上：

$$\mathcal{L}_{\text{ortho}} = \|\hat{C}\hat{C}^\top - I_K\|_F^2$$

### 三大组件

**1. Decoder-Only Vector Quantization (DVQ)**

去掉 encoder-decoder VQ-VAE 中的连续 latent bypass，decoder 只接收 code embedding，迫使所有重建信号经过离散瓶颈。用 Gumbel-Softmax 替代不可微的 nearest-neighbor assignment：

$$y_{\text{soft}} = \text{GumbelSoftmax}(z; \tau), \quad y_{\text{hard}} = \text{one-hot}(y_{\text{soft}})$$
$$h = y_{\text{hard}}^\top C$$

配合 straight-through estimator 反传梯度。训练时 $\tau$ 从 0.4 退火到 0.01（前 300 epoch 不变，300-400 指数衰减），hardness 系数从 0 线性升到 1（150-200 epoch）。

codebook utilization loss 用自信息熵：

$$\mathcal{L}_{\text{util}} = -H(q) = \sum_{k=1}^K q_k \log(q_k)$$

**2. Structure-Preserving Sparse Projection**

不学习稠密映射，而是用固定的稀疏投影矩阵 $P \in \{0,1\}^{D' \times D}$（$D' \gg D$），随机选 $D$ 个唯一行索引做 identity mapping，其余填零：

$$e_k = P c_k$$

证明：$P^\top P = I_D$，因此 $e_i^\top e_j = c_i^\top c_j$，正交结构严格保持。投影冻结，不参与 LLM fine-tuning。

**3. Two-Stage Orthonormal Regularization**

- Stage 1（DVQ 训练）：$\mathcal{L}_{\text{DVQ}} = \mathcal{L}_{\text{rec}} + \lambda_{\text{ortho}} \mathcal{L}_{\text{ortho}} + \lambda_{\text{util}} \mathcal{L}_{\text{util}}$
- Stage 2（LLM fine-tuning）：冻结原始 text embedding，只优化 projected motion embedding 和 LLM 权重，同时继续施加正交正则：

$$\mathcal{L}_{\text{tuning}} = -\mathbb{E}_{(X,Y)} \sum_{t=1}^{|Y|} \log p_\theta(y_t | y_{<t}, X) + \lambda'_{\text{ortho}} \|\hat{E}\hat{E}^\top - I_K\|_F^2$$

### 实现细节

- Codebook：$K = 512$ codes，维度 512
- DVQ 训练：500 epochs，batch 512，AdamW，lr $2 \times 10^{-4}$（codebook 用 $1 \times 10^{-4}$），cosine schedule + 3% warmup
- LLM fine-tuning：100 epochs，batch 320，lr $1 \times 10^{-4}$，cosine annealing $T_{\max}=200$
- Backbone：GPT-2 全参数微调最优；Qwen3-0.6B 和 LLaMA 3.2-1B 用 LoRA（rank 16, scaling 32）但性能下降
- Motion 表示：263 维特征向量（HumanML3D），20 FPS，序列长度 20-200 帧
- DVQ 用 strided 1D convolution 做时序下采样，每个 token 对应原始动作的固定时间窗口

## 局限与 Gap

**作者自述**：
1. **只评估了 motion understanding**（captioning + retrieval），未评估 motion generation（text-to-motion、unconditional generation、controllable generation）。正交 codebook 对生成任务是否同样有效尚不明确。
2. **几何约束只探索了正交性**，未对比 whitening、spectral 约束或 entropy-based 方法等其他几何感知目标。
3. **Retrieval 指标略低于 MotionGPT3**（R@1 0.533 vs 0.573，MMDist 2.68 vs 2.43），captioning 大幅领先但检索对齐仍有提升空间。

**观察到的 Gap**：
4. Codebook 大小固定 $K=512$，未探索不同 codebook size 的影响——当 $K$ 增大时正交约束是否仍有效（$K > D$ 时严格正交不可能，论文未讨论）。
5. 只在 GPT-2 上取得最好结果，更大的 LLM（Qwen3-0.6B、LLaMA 3.2-1B）用 LoRA 适配反而更差。这是 LoRA 的限制还是正交对齐方案与 LoRA 不兼容，缺乏分析。
6. 时序下采样后每个 token 覆盖的时间窗口大小、下采样率等关键超参未详细报告。
7. 未与 RQ-VAE、FSQ 等近期离散量化方法对比，只用了 PQ-VAE 作 tokenizer baseline。

## 与 ReMoMask V2 的关联

### 与 Plan A（latent 对齐检索）的关联

GeoMotionGPT 的核心问题——**codebook 空间和下游模型 embedding 空间之间的几何失配**——与 Plan A 的动机高度同构。ReMoMask V2 Plan A 要把检索空间从 Part_TMR 对比空间迁移到 VQ-VAE latent space，面临的核心挑战正是：检索 query/key 的几何结构要与生成器实际使用的 latent 一致。

可借鉴的具体技术：
- **正交正则化 on codebook**（$\mathcal{L}_{\text{ortho}}$）：ReMoMask 的 RVQ codebook 也可施加类似正交约束，让不同 code 之间最大化区分度，改善检索时的 nearest neighbor 质量。
- **稀疏投影的保结构思路**：如果 Plan A 需要把低维 VQ latent 映射到更高维的检索空间，可用类似的固定稀疏投影替代可学习映射，避免几何失真。
- **DVQ 的 Gumbel-Softmax 量化**：ReMoMask 当前用 RVQ，DVQ 提供了一种完全可微的替代方案，允许对 codebook 施加任意可微正则。

### 与 Plan B（迭代动态检索）的关联

关联较间接。DVQ 产生更均匀的 codebook 使用分布，意味着每步生成的 token 序列更多样化，理论上为迭代检索提供更丰富的 query 信号。但论文本身未涉及迭代 / 动态检索场景。

### 关键启示

GeoMotionGPT 从**几何对齐**角度改善 codebook quality，而 ReMoMask V2 的 Plan A 需要在**同一 latent space 里同时做检索和生成**。两者的交汇点在于：高质量、几何结构良好的 codebook 是 latent-aligned retrieval 的基础设施——如果 codebook 本身 collapse 严重或 code 之间几何关系混乱，在 latent space 做检索的效果上限就会受限。
