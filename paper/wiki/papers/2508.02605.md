## 一句话总结

ReMoMask 将检索增强（RAG）引入基于 masked modeling 的动作生成框架，通过双向动量对比学习（BMM）扩大负样本池提升跨模态检索精度，并用语义时空注意力（SSTA）在 2D token map 上融合文本与检索特征，在 HumanML3D 和 KIT-ML 上取得当时最优的 R-Precision 和 MM Dist。

## 解决什么问题

Text-to-Motion（T2M）生成面临两类问题：

1. **纯生成模型**（扩散模型、自回归模型）存在多样性不足、误差累积、物理不合理等缺陷。
2. **现有 RAG-T2M 方法**（ReMoDiffuse、ReMoGPT）存在 diffusion inertia、partial-mode collapse、异步伪影（asynchronous artifacts）等问题。具体而言：
   - 检索器使用 mini-batch 内负样本训练，负样本数量有限，表征学习不充分。
   - 将文本条件与 1D motion token 简单拼接，无法有效建模文本条件、运动时空信息与检索知识之间的关系。

## 核心方法

ReMoMask 基于 MoMask 的 RVQ-VAE 架构（见 Figure 2），包含三个核心创新：

### 1. 双向动量文本-运动建模（BMM）

受 MoCo 启发，引入双动量编码器 $\hat{f}_m$、$\hat{f}_t$ 和两条负样本队列 $Q_m$、$Q_t$（大小 65536），将负样本数量与 mini-batch 大小解耦。动量编码器通过指数滑动平均更新：

$$\hat{\theta}_m = \tilde{m} \cdot \hat{\theta}_m + (1 - \tilde{m}) \cdot \theta_m$$

双向对比损失为：

$$\mathcal{L}_{\text{BMM}} = \mathcal{L}_{M2T} + \mathcal{L}_{T2M}$$

其中 $\mathcal{L}_{M2T}$ 以 motion 为 query、队列 $Q_t$ 中文本为负样本，$\mathcal{L}_{T2M}$ 方向相反（Algorithm 1）。实际训练中采用 part-level motion encoder（将全身运动分为 6 个部位分别编码后拼接重投影），最终训练目标为 $\mathcal{L}^{pl}_{\text{BMM}}$。

超参数：动量系数 $\tilde{m}=0.99$，温度 $\tau=0.07$，队列大小 65536，8×A800 GPU，batch size 128，200 epochs。

### 2. 语义时空注意力（SSTA）

不同于 MoMask 的 1D token 序列，ReMoMask 使用 **2D RVQ-VAE** 将运动量化为 2D token map $\in \mathbb{R}^{T \times J}$（$T$=帧数，$J$=关节数），保留时间和空间两个维度的信息。

2D token map 加上 2D 位置编码后展平为 1D，然后重新定义注意力的 Q/K/V（见 Figure 2(c)，Eq. 8-11）：

$$Q = m, \quad K = \text{concat}(z, t, [R_m; R_t]), \quad V = \text{concat}(z, t, R_m)$$

$$A_{\text{ssta}}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}} + P\right) V$$

其中 $R_m$、$R_t$ 分别为检索得到的 motion 和 text 特征。残差 Transformer 使用去掉检索特征的简化版本 STA。

### 3. RAG-Classifier-Free Guidance（RAG-CFG）

将 CFG 扩展到 RAG 场景，以 $\{t, R_t, R_m\}$ 为条件：

$$\text{logits} = (1+s) \cdot \text{logits}_{\text{con}} - s \cdot \text{logits}_{\text{un}}$$

其中 guidance scale $s=4$，训练时以 10% 概率进行无条件采样。

### 生成流程

2D RVQ-VAE encoder 量化运动 → Part-Level BMM Retriever 检索文本和运动特征 → 2D Retrieval-Augmented Masked Transformer 生成 base-layer tokens（SSTA 融合条件）→ 2D Residual Transformer 逐层预测残差 tokens（STA）→ 2D RVQ-VAE decoder 重建运动。

2D RVQ-VAE 采用两个 codebook：joint VQ codebook（256 codes，dim 1024）和 global VQ codebook（256 codes，dim 1024）。M-trans：6 layers / 8 heads / dim 512；R-trans：6 layers / 6 heads / dim 384，5 residual layers。

### 消融实验（Table 4 — HumanML3D）

- 去掉 BMM：Top1 R-Precision 从 0.531 降至 0.445（-16.2%），FID 从 0.411 升至 0.825（-50.18%）
- 去掉 SSTA（改用拼接）：MultiModality 从 2.823 降至 1.094（-61.2%），MM Dist 从 2.865 升至 3.04
- 去掉 RAG-CFG：Top1 R-Precision 从 0.531 降至 0.411（-22.6%）
- 去掉局部检索（改用全局）：Top3 R-Precision 从 0.813 降至 0.733（-9.8%）

### 用户研究（50+ 参与者）

- 真实感：ReMoMask vs GT 获 42% 偏好；vs MoMask 67%；vs ReMoDiffuse 75%
- 文本对齐：ReMoMask vs GT 获 47% 偏好；vs MoMask 72%；vs ReMoDiffuse 86%

## 与 TPAMI 可信版本（pami.tex）的差异（updated 2026-07-05）

以下事实以唯一可信 LaTeX 版本 `D:\tpami\currentversion\v2working\pami.tex`（标题 "ReMoMask-2: Latent Retrieval-Augmented Masked Motion Generation"）为准，与本条目记录的 arXiv 版存在差异：

- **SSTA 信息路由**：pami.tex 发表版为 $Q = W_q z$；$K = W_k\,\text{concat}(z, h_{sem})$，$h_{sem} = \text{MLP}(\text{concat}[t; R_t; R_m])$；$V = W_v\,\text{concat}(z, R_m)$——正文明确声称 t、$R_t$ 不进 Value（"domain mismatch"），即 K-only w.r.t. $R_t$。与本条目 arXiv 版 Eq. 8-11（V 含 t）表述不同。
- **动量系数**：pami.tex 为 $\mu = 0.999$（本条目按 arXiv 记 0.99）。
- **主数字**（20 repeats 完整 pipeline）：HumanML3D FID **0.026**、Top1 **0.566**（全场最佳）；检索 HBM R@1 t2m **18.49**；KIT-ML FID 0.131；SnapMoGen FID 13.509。本条目 arXiv 表的 FID 0.099 / Top1 0.531 已被取代，「FID 劣于 MoMask」的观察在可信版本中不再成立。

## 局限与 Gap

### 作者承认的局限

1. **模型规模大**：BMM 双队列 + SSTA 2D attention 使参数量达 238M，不利于实时部署。
2. **短序列验证**：实验主要在 <100 帧的短序列上进行，缺乏舞蹈等需要强时空一致性的复杂动作验证。
3. **抽象描述困难**：Part-level retrieval 依赖预定义运动分区，对 "jumping joyfully" 等抽象描述效果不佳。
4. **缺乏物理约束**：生成的运动可能违反生物力学约束（如关节旋转极限），因为没有引入基于物理的验证。

### 额外观察

5. **HumanML3D FID 并非最优**：FID=0.099 劣于 MoMask（0.045）和 MoGenTS（0.033），该方法的优势集中在 R-Precision、MM Dist 和 MultiModality 上。（注：仅 arXiv 版数字；可信版 pami.tex 报 FID 0.026、全场最佳，见上方差异节，updated 2026-07-05）
6. **表间 FID 不一致**：Table 1 报告 FID=0.099，但 Table 4 消融中完整模型 FID=0.411，二者差异显著且未解释。
7. **Motion→Text 检索高 recall 指标偏弱**：BMM 的 motion-to-text R5（25.75）和 R10（34.61）显著低于 PL-TMR（28.34、39.11），MedR（25.00）也更差。
8. **评估数据集有限**：仅在 HumanML3D 和 KIT-ML 上评估，未涉及 BABEL 等更大规模或更多样的 benchmark。
9. **参数效率低**：BMM retriever 达 238M 参数，是 PL-TMR（118M）的两倍，性能提升与参数增长不成比例。
