核心架构术语

RVQVAE

ReMoMask 的双路径运动量化器，内含一条 1D 路径（全局动作序列）和一条 2D 路径（逐关节组序列），两路各自经过编码器、残差向量量化、解码器，最终通过 linear_out 融合为统一的 263 维重建输出。

设计决策：将动作同时以"整体时间序列"和"时间 x 关节组"两个视角量化，1D 路径捕捉全局协调性，2D 路径保留身体部位的局部细节。

Encoder1d (Encoder)

1D 时间卷积编码器，将 (B, 263, T) 的全局动作表示通过多层 stride-2 下采样（Conv1d + Resnet1D 块）压缩到 (B, code_dim1d, T/4) 的隐码。下采样层数由 down_t 控制（默认 3 层，4x 下采样）。

Avoid: 全局编码器（容易与 MotionEncoder 混淆）

Decoder1d (Decoder)

Encoder1d 的镜像结构，通过 Resnet1D 块 + nearest 上采样将量化隐码还原为 (B, T, 263) 的动作序列。解码器内部使用 reverse dilation 的 ResNet 块。

Encoder2d

2D 时空卷积编码器，输入 (B, D=12, T, J)（每个关节 12 维特征 x 时间 x 关节组数），通过 Conv2d + Resnet2D 块在时间和关节两个维度同时下采样，输出 (B, code_dim2d, T/4, 6)。进入编码器前，22 个关节会 pad 到 24 个以适配 2x 下采样。

MaskTransformer

1D 掩码 transformer，处理全局 token 序列（仅时间维度）。对应训练器中的 mask_transformer_aux，负责预测被掩盖的全局 VQ token。使用标准 TransformerEncoder + CLIP 文本条件 + cosine masking schedule。

models/transformer/transformer_aux.py:86 — class MaskTransformer(nn.Module)

Avoid: 主 transformer（实际上它是辅助路径，主路径是 MaskTransformer2D）

MaskTransformer2D

2D 掩码 transformer，处理 (T, J=6) 的时空 token 网格。对应训练器中的 mask_transformer_ts。核心创新是使用 SemanticsModulatedAttention (SSTA) 代替标准 TransformerEncoder，通过 RAG 检索的运动-文本特征调制 attention。同时采用两阶段掩码（先时间掩码再空间掩码）和 2D positional encoding。

设计决策：在同一个 transformer 中同时建模时间维度和关节组维度的依赖关系，而非分别用两个独立 transformer。SSTA 层将文本和 RAG 检索信息融合进 attention 的 key-value 对。

ResidualTransformer (在 transformer_aux.py 中)

1D 残差 transformer，在第一层量化码之上逐层预测后续量化层的 token。输入是前 k 层 token embedding 的累加和，输出第 k+1 层的 token 预测。使用 quantizer layer id 的 one-hot embedding 作为额外条件。

models/transformer/transformer_aux.py — class ResidualTransformer(nn.Module)

ResidualTransformer2D

2D 残差 transformer，功能与 ResidualTransformer 相同但在 (T, J) 的 2D 网格上工作。支持三种 attention 模式：主序列 attention（flatten 的 T*J）、关节维 attention（attnj，J 个 token 间 attend）、时间维 attention（attnt，T 个时间步间 attend）。token embedding 权重可选 shared codebook 或独立 codebook，可选 share weight（embed 和 output projection 共享参数）。

设计决策：残差 transformer 的训练采用 q_schedule 随机采样活跃量化层，使每层都能学到有效残差。

models/transformer/transformer_ts.py:800-1303 — class ResidualTransformer2D(nn.Module)

SemanticsModulatedAttention (SSTA)

语义调制注意力模块。将文本 prompt xf、RAG 检索到的运动特征 re_motion 和文本特征 re_text 三者融合为 info token，然后把 info token 拼接到 motion token 序列的 key 和 value 中参与 multi-head attention。具体流程：

  1. Q = W_q · LayerNorm(z)，只来自 motion token
  2. info = MLP([t; mean(R_m); mean(R_t)])，三路拼接后过两层 MLP
  3. K = W_k · [z, info]，motion token 和 info token 拼接
  4. V = W_v · [z, mean(R_m)]，只使用 motion 域特征（不混入文本特征）
  5. 标准 scaled dot-product attention + output projection

条件控制通过 cond_type 实现：cond_type % 10 > 0 决定是否使用文本条件，cond_type // 10 > 0 决定是否使用 RAG 检索条件。训练时随机采样 cond_type（0-99），实现 10% 文本 dropout 和 10% RAG dropout。

设计决策：value 只注入运动域特征、不注入文本特征，因为最终输出是运动 token 的预测——文本信息通过 key 影响 attention 权重分布，但不直接混入 value 避免"语义泄漏"。

models/transformer/semantics_modulated.py:16-128 — class SemanticsModulatedAttention(nn.Module)

MoCoTMR

基于动量对比学习的文本-运动检索模型（Momentum Contrast Text-Motion Retrieval）。维护在线编码器和动量编码器各一套（motion + text），外加三组 queue（全局 motion queue、text queue、6 个 body part queue）。使用 InfoNCE loss 训练全局对齐，配合 HBM loss 训练部位级对齐。动量系数默认 0.99，queue 大小 65536。

MocoTmrRetriever

封装了 MoCoTMR 的推理态检索器。加载预计算的 motion/text embedding 数据库，对输入 caption 编码后计算 cosine 相似度排序，取 top-k 个最近邻运动（去重同一动作的不同变体），返回 re_dict。支持 use_shuffle 在候选池中随机打乱以增加多样性。

MotionEncoder

将动作序列编码为固定长度向量的部位级 transformer 编码器。为 6 个身体部位各维护一个独立的 transformer encoder（不共享参数），每个部位编码器前置一个 emb_token（类似 BERT 的 [CLS] token），取 transformer 输出的第 0 位作为该部位的 embedding。输出三种特征：global（6 个部位 mean pool, (B, 512)）、parts（堆叠, (B, 6, 512)）、concat（拼接, (B, 3072)）。

算法术语

Residual Vector Quantization (RVQ)

多层级向量量化方法（参照 SoundStream 的 Algorithm 1）。第 1 层量化器处理编码器输出，后续每层量化前一层的残差。训练时通过 quantize dropout 随机丢弃后 k 层以增强鲁棒性。ReMoMask 对 1D 和 2D 路径各维护一组独立的 RVQ（quantizer1d 和 quantizer2d），codebook 可选共享或独立。

Cosine masking schedule

决定训练和生成过程中掩码比例的调度函数：mask_ratio = cos(t * pi / 2)，其中 t 从 0 到 1。t=0 时掩码比例为 1（全部掩码），t=1 时为 0（无掩码）。生成时 timestep 从 0 线性推进到 1，每步揭示一批新 token。这保证早期步骤做大范围预测（低信心），后期做精修（高信心）。

Avoid: cosine annealing（那是学习率调度，不同概念）

时间掩码 (Temporal mask)

MaskTransformer2D 训练的第一阶段掩码：在时间维度上采样要掩码的帧（batch_randperm < num_token_masked），被选中时间步的所有 J=6 个关节组同时被掩码。掩码后的 token 按 BERT 策略处理（88% 替换为 mask_id，10% 替换为随机 token，2% 保持不变）。

models/transformer/transformer_ts.py:437-456 — MaskTransformer2D.forward 中 # ========== temporal mask

空间掩码 (Spatial mask)

MaskTransformer2D 训练的第二阶段掩码：在展平后的 (T*J) token 序列上独立采样掩码位置，已被时间掩码覆盖的位置排除在外（mask & ~mask_time）。空间掩码允许同一帧内的不同关节组被独立掩码。

设计决策：先做时间掩码再做空间掩码，二者互斥。时间掩码让模型学习跨帧预测，空间掩码让模型学习同帧内的关节依赖。两阶段共同使用同一个 cosine schedule 采样掩码比例。

Classifier-free guidance (CFG)

推理时增强条件信号的技巧。对每个输入分别做条件生成和无条件生成（force_mask=True），最终 logits 按线性外推组合：scaled = uncond + (cond - uncond) * cond_scale。cond_scale 越大，生成结果越贴合文本条件但多样性下降。在 MaskTransformer2D 中，CFG 的条件 dropout 通过 mask_text_and_retr_cond 控制，同时覆盖文本和 RAG 条件。

HBM contrastive loss

Hierarchical Body-part Motion Loss，MoCoTMR 的核心训练目标。包含两层对齐：

  • 实例级 (L_Inst)：标准双向 InfoNCE，将全局运动特征和文本特征在 embedding 空间对齐。正样本来自动量编码器，负样本来自 queue。
  • 部位级 (L_Part)：对 6 个身体部位分别计算与文本的 InfoNCE loss，正样本为对应部位的动量特征，负样本来自该部位的 part queue。

总 loss = L_Inst + lambda_part * L_Part，其中 lambda_part 默认 1.0。温度参数 tau = 0.07。

动量编码器 (Momentum encoder)

MoCoTMR 中的慢更新编码器副本，参数按指数移动平均跟踪在线编码器：theta_m = momentum * theta_m + (1 - momentum) * theta。动量系数默认 0.99。动量编码器生成的特征用作 InfoNCE 的正样本（positive key），并入队作为后续 batch 的负样本。模型维护 4 对动量参数对（motion encoder、motion projection、text encoder、text projection）。

Commitment loss

量化器的正则化损失，定义为编码器输出与其量化码的 MSE：F.mse_loss(x, x_d.detach())。鼓励编码器输出"靠近"codebook 向量，防止编码器输出在空间中漫游导致量化不稳定。梯度只反传到编码器（x_d.detach()），codebook 通过 EMA 更新。在 RVQ 中，所有量化层的 commitment loss 取平均。

Quantize dropout

RVQ 训练的正则化技巧：以概率 quantize_dropout_prob（默认 0.5）随机截断后续量化层，被截断的层输出 null_indices = -1。让解码器学会在仅有前 k 层量化码的情况下也能合理重建，提升推理时对量化层数的鲁棒性。

q_schedule

ResidualTransformer2D 训练时采样活跃量化层索引的调度函数：q = round((1 - cosine_schedule(noise)) * (high - low - 1)) + low。倾向于选择较浅层（小索引概率更高），因为浅层残差更大、更重要。

re_dict

RAG 检索结果的标准数据结构，由 MocoTmrRetriever.forward() 返回。包含两个 key：

  • re_motion: (B, K, 1, D) — 检索到的 K 个运动的 embedding，D=512
  • re_text: (B, K, 1, D) — 对应 K 个运动的文本 caption embedding

这两组特征在 SSTA 中被 squeeze 为 (B, K, D) 后 mean-pool 为 (B, 1, D)，分别作为 R_m 和 R_t 参与 info fusion 和 value 构建。K 默认值由 cfg.rag.top_k 控制。

EMA codebook 更新

codebook 向量不通过梯度更新，而是使用指数移动平均（Exponential Moving Average）跟踪编码器输出的聚类中心。更新公式：code_sum = mu * code_sum + (1 - mu) * batch_sum，code_count = mu * code_count + (1 - mu) * batch_count，codebook = code_sum / code_count。使用计数低于 1 的码字（死码）会被随机重置为当前 batch 中的向量（QuantizeEMAReset 的 Reset 含义）。

Gumbel sampling

量化器和生成器中用的随机采样方法。在 logits 上加入 Gumbel 噪声后取 argmax：sample = argmax(logits/temp + gumbel_noise)。温度参数控制随机性：temp → 0 趋近于 greedy，temp → inf 趋近于均匀采样。量化器默认 sample_codebook_temp=0.5。

Perplexity (codebook 利用率)

衡量 codebook 利用是否均匀的指标，计算方式为 exp(-sum(p * log(p)))，其中 p 是各码字的使用频率。perplexity 等于 codebook 大小说明所有码字被均匀使用；接近 1 说明严重坍缩。在训练日志中用于监控 codebook 健康度。
