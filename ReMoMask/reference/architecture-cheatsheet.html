5. 训练命令速查

Stage 1: RVQ-VAE 训练

bash run_rvq.sh rvq_nq6 0 humanml3d \ --batch_size 256 \ --num_quantizers 6 \ --max_epoch 50 \ --quantize_dropout_prob 0.2 \ --gamma 0.1 \ --code_dim2d 1024 \ --nb_code2d 256

脚本: run_rvq.sh → train_vq.py。单 GPU 训练，约 50 epoch 收敛。checkpoint 存入 logs/humanml3d/<name>/model/

Stage 2: Mask Transformer 训练 (DDP)

bash run_mtrans.sh mtrans_ssta 2 0,1 humanml3d 11234 \ --vq_name rvq_nq6 \ --batch_size 64 \ --max_epoch 2000 \ --milestones 1000000 \ --attnj --attnt

脚本: run_mtrans.sh → train_mask_transformer_ddp.py。参数 2 = nproc_per_node (GPU 数)，11234 = master_port。同时训练 1D (aux) 和 2D (ts) 两个 Mask Transformer。

Stage 3: Residual Transformer 训练 (DDP)

bash run_rtrans.sh rtrans_sw 2 0,1 humanml3d 12347 \ --batch_size 64 \ --vq_name rvq_nq6 \ --cond_drop_prob 0.01 \ --share_weight \ --max_epoch 2000 \ --milestones 1000000 \ --attnj --attnt

脚本: run_rtrans.sh → train_res_transformer_ddp.py。需要已训练好的 VQ-VAE checkpoint。

训练顺序是严格的: VQ-VAE 先行 → Mask Transformer (依赖 VQ codebook) → Residual Transformer (依赖 VQ codebook)。 长度预测器单独训练，checkpoint 固定存于 checkpoints/<dataset>/length_estimator/model/finest.tar。 demo.py:150-156

6. 推理命令速查

demo.py 使用方式 demo.py:166-356

# 单条文本生成 python demo.py \ --gpu_id 0 \ --ext demo_output \ --text_prompt "a person walks forward and turns around" \ --motion_length 196 \ --mtrans_name mtrans_ssta \ --rtrans_name rtrans_sw \ --time_steps 18 \ --cond_scale 5 \ --temperature 1 \ --topkr 0.9 \ --gumbel_sample
# 批量文本生成 (从文件读取) python demo.py \ --gpu_id 0 \ --ext batch_demo \ --text_path input_prompts.txt \ --mtrans_name mtrans_ssta \ --rtrans_name rtrans_sw

input_prompts.txt 格式: 每行 text_prompt=frame_count，如 a person jumps=120。省略帧数则自动用 LengthEstimator 预测。
输出目录: ./outputs/<ext>/joints/ (npy) 和 ./outputs/<ext>/animations/ (mp4 + bvh)。

推理流水线执行顺序 demo.py:298-329

步骤组件输入输出
0retriever(captions)文本列表re_dict 检索特征
1retriever.encode_text()文本列表caption_embedding (b, 512)

模型加载顺序很重要: VQ-VAE 先加载 (code_dim1d/code_dim2d/num_code1d/num_code2d 从 VQ checkpoint 读取)， 然后用这些维度信息初始化 Mask/Residual Transformer。 demo.py:190-214
CFG (Classifier-Free Guidance) 的两种实现:
1D Mask Transformer (transformer_aux.py:311-329): 标准 CFG，mask_cond 将 embedding 置零 → scaled = uncond + (cond - uncond) * scale。
2D Mask Transformer (transformer_ts.py:328-338): 通过 cond_type 三路控制 -- text 条件、RAG 条件可分别开关， %10 > 0 控制 text，//10 > 0 控制 retrieval。训练时随机采样 cond_type in [0,100)，10% 概率丢弃各条件。

附: 关键设计决策一览

决策做法位置
双流量化而非单流 1D 全局流保留整体动态连贯性；2D 关节流保留空间精度。末端 linear_out 融合。 model.py:10-140
关节维度 pad 到 24 22 关节 pad 到 24 确保 2 次 stride-2 Conv2d 整除，降采样后得 J=6 body parts。 model.py:89-91
逐关节独立量化 (B*J, D, T) 输入 quantizer2d -- 不同关节共享 codebook 但独立量化，保留身体部位独立性。 model.py:94, 118
SSTA 替代标准 self-attention 在 2D transformer 中，用 SemanticsModulatedAttention 将 text、retrieval motion、retrieval text 三路条件注入 key/value。 transformer_ts.py:219-222
Value 只注入 motion 特征 SSTA 的 V = W_v([z, R_m]) 不含 text embedding，避免语义信息直接覆盖运动细节。 semantics_modulated.py:99-102
训练时 temporal+spatial 二阶段 masking 先按时间步 mask 整行 (全关节)，再按 spatial 位置 mask 未被覆盖的 token。双重 masking 同时学到时空结构。 transformer_ts.py:437-479
Residual Transformer 逐层自回归 不做 mask-predict 迭代，而是按 quantizer 层级从第 1 层到第 Q-1 层逐步预测，history_sum 累加。 transformer_aux.py:947-980
RAG 条件独立于 text 条件 RAG 只送入 2D transformer 的 SSTA，1D transformer 仅接收 text embedding -- 因为关节级检索对 spatial 分支更有价值。 demo.py:314-325
MoCo-TMR 作为统一 encoder 推理时 text encoding 统一由 retriever.encode_text() 完成 (而非各 transformer 的 CLIP)，保持 embedding 空间一致。 demo.py:306-307
cosine schedule 控制 mask 比例 cos(t * pi/2): t=0 时 mask 100%，t=1 时 mask 0%。在 mask-predict 迭代中逐步揭露 token。 tools.py:120-121
