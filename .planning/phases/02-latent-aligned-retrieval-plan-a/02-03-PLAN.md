   - __init__(self, clip_dim=512, ze_dim=None):
     - ze_dim 从 LA-01 的 summary.json 读取 code_dim2d（或构造时传入）
     - self.mlp = nn.Sequential(

     - 输出: (B, ze_dim) 映射到 z_e 空间的向量
     - projected = self.mlp(clip_text_embedding)
     - return F.normalize(projected, dim=1)  # L2 normalize

  <action>
新建 ReMoMask/train_query_projector.py，独立训练 query_projector:

1. 数据准备:
   - 加载训练集 (text, motion) 对: 用与 build_rag_database.py 相同的数据遍历逻辑，读 train.txt，加载每个 motion 的 caption
   - 预计算并缓存两组特征:
     a. z_e features: 加载 database_ze/encoded_motions.npy (N, 1, code_dim2d) -> squeeze -> (N, code_dim2d)
     b. CLIP text features: 加载 database_ze/encoded_texts_clip.npy (N, 1, 512) -> squeeze -> (N, 512)
     c. BMM teacher scores: 加载原 database/encoded_motions.npy (Part_TMR 空间)，用 MocoTmrRetriever 的 cal_text_motion_sim 计算每个 text 对全库 motion 的相似度分布 (N, N)，作为 teacher soft target

2. 训练循环:
   - Epoch loop, batch_size=128 (per D-15)
   - 每个 batch:
     a. 取 batch_size 个 (clip_text, z_e_motion) 对
     b. projected = projector(clip_text)  # (B, ze_dim)
     c. 计算 student distribution: cosine_sim(projected, all_ze_motions) / temperature -> softmax  # (B, N)
     d. 计算 teacher distribution: bmm_sim(clip_text, all_bmm_motions) / temperature -> softmax  # (B, N)
     e. loss = KL(teacher_dist || student_dist)  per D-06: KL(projector(clip_text) || z_e_motion)

   注意 KL 散度方向: per D-03 LOCKED-03，用 KL 而非 InfoNCE。per D-06 的公式，teacher 是 z_e 空间的 ground truth 分布。

   实际实现方案:
   - teacher signal 来自 BMM (per D-07): 用 Part_TMR 的 text-motion similarity 作为 soft target ranking
   - student 是 projector 投出的 text 在 z_e 空间中的 similarity distribution
   - loss = F.kl_div(student_log_prob, teacher_prob, reduction='batchmean')

3. 优化器: Adam, lr=1e-4 (可调)
   - 200 epochs (per D-15 参考 Part_TMR 配置)
   - 每 10 epochs 评估 R@1/R@5: projector(text) 在 z_e 空间的检索准确率

4. 效率优化:
   - 全库相似度计算 (B, N) 对于 N=23K 可能内存不够
   - 解决方案: 每个 text 只取 BMM teacher 的 top-256 作为 candidate set，对 candidate set 计算 KL
   - 或者用 mini-batch 内的负样本（in-batch negatives）+ 一组固定的 hard negatives

5. 保存:
   - 每个 epoch 保存 projector checkpoint 到 logs/query_projector/
   - 保存 best model (按 R@1)
   - 训练完成后，用 best projector 重新编码所有 text:
     projected_texts = projector(all_clip_texts)  # (N, ze_dim)
     保存到 database_ze/encoded_texts.npy (N, 1, ze_dim)
   - 这个 encoded_texts.npy 是最终的 text feature 库，替代之前的 encoded_texts_clip.npy

6. 命令行参数:
   --database_ze_path (默认 database_ze)
   --database_bmm_path (默认 database，原 Part_TMR 库)
   --output_dir (默认 logs/query_projector)
   --epochs (默认 200)
   --batch_size (默认 128)
   --lr (默认 1e-4)
   --temperature (默认 0.07，与 Part_TMR 一致)
   --device (默认 cuda:0)

注意事项:
- projector 只有 2 层 MLP，参数量很小（约 512*1024 + 1024 + 1024*1024 + 1024 = 约 1.6M），训练应该很快
- 确保 z_e features 和 CLIP text features 都已 L2 normalize
- 训练时冻结 CLIP 和 RVQVAE，只更新 projector
