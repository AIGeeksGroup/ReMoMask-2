修改 SemanticsModulatedAttention，添加 retrieval_dim 参数和对应投影层:

   新: def __init__(self, latent_dim, text_latent_dim, num_heads, dropout, rt_in_value=False, retrieval_dim=None)

2. 添加投影层（在 self.out_proj 定义之后）:
   - retrieval_dim 默认为 None，表示与 latent_dim 相同（向后兼容 V1）
   - self.retrieval_dim = retrieval_dim if retrieval_dim is not None else latent_dim
   - 如果 self.retrieval_dim != latent_dim:
     self.re_motion_proj = nn.Linear(self.retrieval_dim, latent_dim)
     self.re_text_proj = nn.Linear(self.retrieval_dim, latent_dim)
   - 否则:
     self.re_motion_proj = nn.Identity()
     self.re_text_proj = nn.Identity()

3. 修改 forward() 中的 re_dict 特征提取（约第 68-69 行）:
   原:
     re_motion = re_dict['re_motion'].squeeze(2)  # (B, K, D_retr)
     re_text = re_dict['re_text'].squeeze(2)      # (B, K, D_retr)
   新:
     re_motion_raw = re_dict['re_motion'].squeeze(2)  # (B, K, D_retr) where D_retr = retrieval_dim
     re_text_raw = re_dict['re_text'].squeeze(2)      # (B, K, D_retr)
     re_motion = self.re_motion_proj(re_motion_raw)    # (B, K, latent_dim)
     re_text = self.re_text_proj(re_text_raw)          # (B, K, latent_dim)

   投影后，re_motion 和 re_text 的最后一维变为 latent_dim，与 xf 和 z_norm 维度一致。
   后续的 R_m_pooled、R_t_pooled、fused_input、info_mlp 逻辑无需修改。

4. 关于 D-09（info_mlp 从 3 路变 2 路）:
   保持 3 路结构不变。z_e 空间中 re_motion 和 re_text 经过投影后在语义上仍然分别代表动作和文本的检索结果。不合并为 2 路，因为:
   - re_motion 来自 z_e 空间的 motion encoding（物理动作表征）
   - re_text 来自 projector 投出的 text encoding（语义文本表征）
   - 两者虽然在同一空间，但承载不同信号，分开有助于 info_mlp 学习差异
   如果后续消融显示 2 路更好，可在 LA-06 中对比。

5. 向后兼容:
   - retrieval_dim=None 时行为与修改前完全一致（Identity 投影）
   - V1 checkpoint 加载不受影响（新参数 re_motion_proj/re_text_proj 会是 missing keys，用 strict=False 加载后随机初始化即可，因为 V2 需要重训）
