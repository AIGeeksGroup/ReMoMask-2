## Critical Anti-Patterns

| 教训 | severity |
|------|----------|
| sbatch 脚本别依赖代码默认超参——必须显式传全 opt.txt 每一项(默认 latent_dim=384 曾导致秒崩) | warning |
| sbatch 里没有 `set -e` 时 Python 崩了 job 仍显示 COMPLETED——所有新 sbatch 脚本必须 `set -e` | warning |
| 远程 sed 注入多行 Python 会踩转义坑——复杂修改先写本地文件再 scp | warning |
