1. 新建 ReMoMask/scripts/run_plan_a_ablation.sh:

   脚本结构:
   - 接受参数: V1_EXP_NAME, V2_EXP_NAME, VQ_NAME, DEVICE
   - Step 1: 评估 V1 (Part_TMR 检索):
     python eval_res.py --name $V1_EXP_NAME --dataset_name humanml3d --vq_name $VQ_NAME --gpu_id $DEVICE
     # 结果自动保存到 logs/humanml3d/$V1_EXP_NAME/eval/ 目录
   
   - Step 2: 评估 V2 (z_e 检索):
     python eval_res.py --name $V2_EXP_NAME --dataset_name humanml3d --vq_name $VQ_NAME --gpu_id $DEVICE --use_ze_retrieval --ze_database_path database_ze --projector_path logs/query_projector/best_projector.pt
     # 注意: eval_res.py 也需要支持 --use_ze_retrieval 标志
     # 如果 eval_res.py 没有该标志，需要在此脚本中小幅修改 eval_res.py

   - Step 3: 对比分析:
     python scripts/compare_v1_v2.py --v1_dir logs/humanml3d/$V1_EXP_NAME/eval --v2_dir logs/humanml3d/$V2_EXP_NAME/eval --output results/plan_a_ablation/

   注意: eval_res.py 和 eval_mask.py 需要与 train 脚本类似的 --use_ze_retrieval 改动。如果 eval 脚本的 retriever 加载逻辑与 train 不同，需要同步修改。检查 eval_res.py 中 retriever 加载方式，添加相同的 V1/V2 分支。

2. 新建 ReMoMask/scripts/compare_v1_v2.py:

   功能:
   - 读取 V1 和 V2 的评估结果文件（通常是 .log 或 .npy 格式，看 eval_res.py 的输出格式）
   - 提取 FID、R-Precision (top-1/2/3)、MM-Dist、Diversity
   - 输出:
     a. 终端打印对比表:
        | Metric    | V1 (Part_TMR) | V2 (z_e) | Delta   |
        |-----------|---------------|----------|---------|
        | FID       | 0.099         | ???      | ???     |
        | R@1       | ...           | ...      | ...     |
        | MM-Dist   | ...           | ...      | ...     |
     b. results/plan_a_ablation/comparison.json: 结构化数据
     c. results/plan_a_ablation/comparison.tex: LaTeX tabular 格式，可直接粘贴到论文

   参数:
   --v1_dir: V1 评估结果目录
   --v2_dir: V2 评估结果目录
   --output: 输出目录（默认 results/plan_a_ablation/）

3. eval 脚本适配:
   eval_mask.py 和 eval_res.py 中也需要支持 ZeRetriever。修改方式与 train_mask_transformer_ddp.py 一致:
   - 添加 --use_ze_retrieval, --ze_database_path, --projector_path 参数
   - retriever 加载分支（Part_TMR vs ZeRetriever）
   - MaskTransformer2D 构造传入 retrieval_dim

   注意: eval 脚本中加载 MaskTransformer2D 时使用 strict=False（因为 V2 checkpoint 有 re_motion_proj/re_text_proj 权重）。V1 checkpoint 评估不传 retrieval_dim（默认 None），自然跳过投影层。
