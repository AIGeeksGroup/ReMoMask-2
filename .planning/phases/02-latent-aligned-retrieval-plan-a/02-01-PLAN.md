  <action>
新建 ReMoMask/scripts/analyze_ze.py，功能如下:

1. 参数解析: 接受 --vq_checkpoint (RVQVAE 权重路径)、--dataset_root (HumanML3D 数据根目录)、--output_dir (默认 results/ze_analysis/)、--device (默认 cuda:0)、--max_samples (默认 2000，用于快速诊断)

2. 加载 RVQVAE:
   - 用 utils/get_opt.py 中的 get_opt() 读取 VQ 模型的 opt.txt 获取 code_dim2d、nb_code2d 等参数
   - 构建 RVQVAE(vq_opt, dim_pose=263, ...) 并加载 checkpoint
   - 打印关键维度: code_dim1d、code_dim2d、num_code1d、num_code2d、J (关节数=6)

3. 提取 z_e:
   - 从 train.txt 读取 motion 文件列表（per D-01, D-02 从 2D 分支提取）
   - 对每个 motion: 加载 raw_motion, 标准化, whole2parts 拆分关节, pad 到 24 关节
   - 调用 vq_model.encoder2d(rearrange(x2d, 'b t j d -> b d t j')) 获得 z_e，形状 (1, code_dim2d, T/4, 6)
   - 对时间维和关节维做 mean pooling: z_e_pooled = z_e.mean(dim=[2, 3])，形状 (1, code_dim2d)
   - L2 normalize
   - 收集所有样本的 z_e_pooled 到一个 tensor，形状 (N, code_dim2d)

4. 几何分析:
   - cosine similarity 分布: 从 N 个向量中随机采样 10000 对，计算 pairwise cosine similarity，绘制直方图
   - 各向异性检查: 计算 z_e_pooled 协方差矩阵的特征值，isotropy_score = min(eigenvalues) / max(eigenvalues)
   - Dimensional collapse 检查: 统计特征值中小于 max_eigenvalue * 0.01 的比例（有效维度占比）
   - 记录 code_dim2d 实际值、z_e_pooled 均值范数、标准差

5. 输出:
   - results/ze_analysis/cosine_sim_hist.png — cosine similarity 分布直方图
   - results/ze_analysis/eigenvalue_spectrum.png — 特征值谱
   - results/ze_analysis/summary.json — 包含 code_dim2d、isotropy_score、effective_dim_ratio、mean_cosine_sim、std_cosine_sim、mean_norm
   - 终端打印关键结果摘要

注意事项:
- 必须用 torch.inference_mode() 包裹前向传播
- whole2parts 来自 Part_TMR/datasets/utils import whole2parts
- motion 标准化: (motion - Mean.npy) / Std.npy，与 build_rag_database.py 一致
- 不改任何现有文件，纯新增脚本
