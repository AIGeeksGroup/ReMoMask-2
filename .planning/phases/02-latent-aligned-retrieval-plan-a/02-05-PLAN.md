  <name>Task 2: 修改 MaskTransformerTrainer 适配新 retriever</name>
  <files>ReMoMask/models/transformer/transformer_trainer_ddp.py</files>
  <action>
MaskTransformerTrainer 需要少量修改以适配 ZeRetriever:

1. text encoding 路径:
   当前 trainer 的 tokenize() 和 encode_text() 方法调用 self.retriever（即 MocoTmrRetriever）的对应方法。ZeRetriever 的 text encoding 走 CLIP + projector，接口不同。

   修改方案: 在 trainer 中检测 retriever 类型:
   - 如果是 MocoTmrRetriever: 用 self.retriever.tokenize() + self.retriever.encode_text() （现有逻辑）
   - 如果是 ZeRetriever: 用 MaskTransformer2D 自带的 CLIP encode_text()

   具体修改 train() 方法中的 caption embedding 部分（约第 227-228 行）:
   原:
     caption_ids = self.tokenize(captions).to(device)
     caption_embedding = self.encode_text(caption_ids)
   新:
     if hasattr(self.retriever, 'model'):  # MocoTmrRetriever has .model
         caption_ids = self.tokenize(captions).to(device)
         caption_embedding = self.encode_text(caption_ids)
     else:  # ZeRetriever
         caption_embedding = self.mask_transformer_ts.module.encode_text(captions)
   
   或者更简洁的方案: 给 ZeRetriever 也实现 tokenize() 和 encode_text() 接口（使用内部的 CLIP model），使得 trainer 代码无需分支。推荐这个方案——在 ze_retriever.py 中添加这两个方法。

2. re_dict 调用不变:
   trainer 的第 220 行 `re_dict = self.retriever(captions)` 和第 272 行相同调用。ZeRetriever.forward() 的签名与 MocoTmrRetriever.forward() 一致，无需修改。

3. 验证逻辑:
   第 252-256 行 evaluation_mask_transformer() 也调用 retriever。确保 eval 时也使用正确的 retriever。这在函数签名中已经传入 retriever=self.retriever，无需修改。

4. val loop（第 271-272 行）: 同样调用 self.retriever(captions)，无需修改。
